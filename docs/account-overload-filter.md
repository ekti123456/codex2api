# 账号 500 标记筛选

账号页提供「全部 / 有 500 标记 / 无 500 标记」，默认全部，可与账号状态、计划、搜索、分组等条件组合。独立切换标记筛选不会改变原有状态筛选；清空筛选会一起重置。

沿用计划徽标变红的规则：健康条最近 20 × 10 分钟统计范围内，存在 HTTP 500 且错误码为 `server_is_overloaded` 的请求即有标记。其他 500、429、503、错误正文仅提及该字符串以及内部能力探测不算；重试成功不会清除窗口内已经发生的过载。无日志或已超出统计范围的账号属于「无标记」，不表示账号健康。

服务端在排序、分页前对全池筛选，批量操作的全筛选选择器也携带同一条件。接口参数为 `overload_500=marked|unmarked`，省略或 `all` 不限；非法参数返回 400。仅启用标记筛选时查询该时段的匹配账号 ID，不下载全池健康桶，也不为每个账号单独查询。读取失败会报错，不当作「无标记」。
