# 首次主会话准入

`codex_initial_session_max_age_seconds` 默认 60 秒，可在系统设置中修改为 1–86400 秒。
配置持久化并热更新，与会话序号校验开关独立。沿用原配置字段，同时限制正负时间差；
例如配置为 60 秒时，允许 ID 时间比网关接收时间早或晚最多 60 秒。

先恢复持久账号绑定、活动绑定或窗口授权归属。已有归属的主会话不限 ID 年龄；
正常切号、fork、标题、子请求和压缩沿用原有归属规则。API 中转豁免路径保持不变。

对仍无绑定、准备首次选号的 Codex 主会话，读取入站原始主会话 UUIDv7 的毫秒时间，
以网关接收该轮请求的时间计算有符号时间差（接收时间减 ID 时间）。
正负时间差的绝对值恰好等于阈值允许，超过阈值或无效 ID 拒绝。
过旧仍记为 `expired`，超前超限仍记为 `future`；容限内的超前时间记为 `allowed`。
单条诊断的 `age_ms` 保留正负号，便于排查两端时钟偏差。
客户端轮次时间不参与授权判断；排队及内部重试不重新计算年龄。

对外 HTTP 400（WS 对应错误事件），使用 `codex_session_identity_unavailable` 和通用提示，
只给出 `retry: stop`，不返回阈值和具体原因。管理员使用日志中的 `initial_session` 保存
判定结果、时间差、阈值和首次出站清理结果。诊断详情与运行状态接口仅供管理员访问。

首次选号通过后，在每次出站边界清除 `X-Codex-Turn-State` 和
`client_metadata.x-codex-turn-state`，覆盖内部重试和 HTTP/WS 转换。
不改写 input、工具或其他历史。已绑定请求继续原有 turn-state 处理。

`/ops/runtime` 显示当前进程的统计：最近一小时（3600 个秒桶）及进程启动以来。
每个进入年龄检查的入站请求只计一次，含拦截；客户端重新提交另计。
平均与最大值按时间差绝对值统计，包含允许、过旧及超前超限的有效 ID，无效 ID 不参与。
计数保留原字段：`rejected` 表示过旧拦截，`future` 表示超前超限拦截，`invalid` 表示无效 ID。
更新 O(1)，快照 O(3600)，不保存会话 ID、不查数据库或扫描日志；重启清零，多实例不汇总。

本功能是保守准入，不是会话真实性证明。提前创建的空对话、客户端时钟偏差、
网关收到请求前的网络或前置服务等待也可能导致拦截。修改 ID 可以改变其自报时间；
不能以该规则替代服务端维护的账号归属。
