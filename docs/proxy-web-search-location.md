# 代理出口 Web Search 地区

系统设置中的「按代理出口地区覆盖 Web Search 位置」默认关闭。开启后，已有的
`web_search` / `web_search_*` 工具使用实际出站代理对应的近似地区。

- 代理单测、批量测试获取英文国家、省州、城市和 IANA 时区，国家代码为两位大写字母。
- 检测结果持久化，不设置过期时间；只有再次测试或编辑代理时更新。重启从数据库恢复。
- 代理编辑支持国家代码、省州、城市和时区。每个字段优先使用手动值，留空使用检测值。
  再次测试只更新检测值，不会覆盖手动值。
- 测试失败保留地区；成功测试仍为同一 IP 且缺少字段时保留旧字段。不同 IP 缺少字段时清空
  对应检测值，防止拼接旧出口的城市。修改代理 URL 清空检测值，保留手动配置。
- 出站时查内存中的代理地区，同一次请求按代理 URL 缓存快照；切换到另一代理重新选取。
  不进行 IP 网络查询或数据库查询。
- 仅改写顶层 `tools[].user_location`，不创建搜索工具，不改写 `input`，兼容完整保留 input 模式。
  开启后以保存地区整体替换客户端位置，缺失字段省略；所有字段都缺失则保留客户端位置。
- 直连、未登记代理、无法确认出口的 Resin 不自动覆盖。当前保存的检测结果代表测试时的出口；
  轮换出口需要再次测试或手动修改。

配置键：`codex_web_search_proxy_location`。
代理检测字段：`test_country_code`、`test_region`、`test_city`、`test_timezone`。
手动字段：`country_code_override`、`region_override`、`city_override`、`timezone_override`。
