# 入站会话前缀观察

活跃窗口和使用统计显示 `session_id_prefix`，只保存入站 `session_id` 的前八位（小写），不新增完整会话 ID 列。支持原生 `Session-Id`／`Session_id`、turn metadata，以及 HTTP、compact、WebSocket `response.create` 的正文元数据。

仅从明确提供且一致的 UUID 会话字段提取。缺失、非 UUID、多个会话字段冲突时留空，界面显示 `-`；不会用线程 ID、turn ID、账号设备 ID、缓存键、NewAPI 根指纹或出站改写值代替。

使用统计默认显示「会话 ID 前缀」列，支持列设置、移动端展示。点击前缀或在现有搜索框输入前缀即可筛选；搜索在服务端执行，与其他筛选、分页及错误摘要联动。相同前缀可能属于不同用户或不同会话，不能单独作为用户身份或父子关系证明；统计字段本身不改变会话锁定或权限。

日志工具栏提供固定请求类别筛选：用户主请求、关联被动、独立后台、关联请求（未判被动）、压缩请求、网关内部、未识别、未记录。筛选依据已保存的 `request_type`，可与前缀搜索组合；「未记录」仅对应历史空值，与已记录为 `unknown` 的「未识别」分开，不根据端点或正文猜测类别。切换类别回到第一页，清除筛选恢复全部。

升级后新日志开始记录；旧日志不批量回填，未采集值显示 `-`。已有活跃窗口可在后续普通主请求续用时补齐缺失前缀，不重置创建时间和到期时间；附属请求不覆盖窗口前缀。原有诊断详情保持原有采集规则。

## 无根请求关联

配套 NewAPI 已改成按「已认证平台/用户/令牌/设备范围 + 入站会话前缀」定位唯一主根，然后签名传递给 Codex2API。缺失、多个候选或根账号不可用均报错，不再按时间最近、最后账号或权重猜号；明确的完整父子/turn 绑定不受影响。

Codex2API 已移除 HTTP Responses、compact、Chat Completions 和 WebSocket 的最近账号回退调用及缓存写入。旧 `codex_unlinked_account_fallback_enabled/seconds` 配置仅兼容保存，不再影响调度；设置页不再展示这两个操作项。`recent_account.enabled` 为 false，身份 `scope_hash` 仍用于诊断，不依赖旧开关。

NewAPI 旧时间别名不迁移，新索引需要主请求重新登记。直连 Codex2API 而没有有效父根的后台请求仍然拒绝；不会在两端各猜一次。该规则可能拒绝实际相关但跨前缀的请求，也无法证明唯一候选一定是真正父根。
