# 使用日志「首轮」标签

端点旁的「首轮」表示该用户轮次的首个逻辑请求，悬停或键盘聚焦显示用户输入的前 20 个 Unicode 字符（超长加省略号）。手机卡片使用相同组件。

新增日志字段：`turn_id`、可空的 `is_turn_first_request`、`turn_prompt_preview`。列表、详情诊断和导出都保留这些信息；摘要只保存短文本，不依赖审计开关或逐行查询审计表。

轮次登记使用入站原始 thread/turn ID 和用户/API Key 隔离范围的摘要，数据库唯一键保证多实例只认领一个逻辑请求。登记发生在身份改写及上游重试之前，重试日志只展示一次标签。不能使用 turn-state 长度、缓存命中率或页面行顺序判断首条。

迁移会保存首次启用时间。旧日志、启用前开始的轮次、缺少或冲突的轮次标识/开始时间均保持未知；首次观测已经是工具续接或压缩时登记未知状态，后续不会补标为首条。自动审核和子代理请求不显示用户轮次标签。

SQLite 和 PostgreSQL 均为增量迁移。轮次登记跨服务重启保留；删除/筛选日志不会把后续请求重新认领为首条。登记表保存标识摘要和请求关联 ID，用户摘要只进入原有使用日志。
